# ICD-O-4 Класифікатор

Двомовний (укр / eng) навігатор морфологічних кодів ICD-O-4: 2390 нозологій, пошук за кодом або частиною діагнозу, копіювання у форматі `Діагноз (ICD-O-4: код)`.

**Відкрити:** https://USERNAME.github.io/icdo4-navigator/

## Пошук
- Код: `80822/3`, `808223`, `8082/3` (усі підтипи), частина коду
- Діагноз українською або англійською, слова в будь-якому порядку
- `Ctrl+K` — фокус на пошук, `Esc` — очистити

Один статичний файл `index.html`, дані вшиті, без збірки й залежностей.

> Переклад не верифікований повністю; записи з позначками конвертера доступні через фільтр «На перевірку».
